# Prismind – סימון נקודות במערכת צירים

גרסה בעיצוב Prismind, תוך שמירה על מנגנון התרגול המקורי:
- בוחרים נקודה מהרשימה.
- מסמנים אותה על מערכת הצירים.
- מקבלים משוב מיידי ✓ / ✕.
- נקודה נכונה נשארת על הגרף.
- אפשר לנסות שוב אחרי טעות.
- כפתור התחלה מחדש.
